## Tips for Better Results

### Be Specific
❌ "Make a chair"
✅ "Create a wooden chair with 4 legs, a seat, and a backrest"

### Include Dimensions
❌ "Create a building"
✅ "Create a building 10 units wide, 15 units deep, and 20 units tall"

### Specify Materials
❌ "Make it look nice"
✅ "Add a brushed metal material with slight roughness"

### Use Iterations
1. Generate base object
2. Lock it
3. Ask for variations
4. Keep the best ones

## Troubleshooting Prompts

If something doesn't work, try being more explicit:

Instead of:
```
Make it bigger
```

Try:
```
Scale the selected object to 2x its current size
```

Instead of:
```
Change the color
```

Try:
```
Change the material base color to blue (RGB: 0.2, 0.3, 0.8)
```
