Blender MCP Launcher (Unsigned Build)
=====================================

This app is unsigned, so macOS may block first launch.

Install and first open flow:

1. Drag "Blender MCP Launcher.app" into "Applications".
2. Open the app once from Applications (it may be blocked).
3. Open System Settings > Privacy & Security.
4. Under Security, click "Open Anyway" for Blender MCP Launcher.
5. Confirm "Open" in the follow-up prompt.

After this first approval, normal double-click launch works.
