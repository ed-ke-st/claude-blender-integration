Place your app icon files in this folder.

Required files:
- icon.png  (used at runtime/dev for BrowserWindow and macOS dock)
- icon.ico  (used by electron-builder for Windows installer/app)
- icon.svg  (editable source for the concept icon)

Optional for Linux builds:
- PNG sizes such as 512x512, 256x256, 128x128 in this folder

Tips:
- Start from a 1024x1024 source image.
- Keep transparent background if possible.
